# LifeHub

LifeHub es una aplicación web personal para organizar tareas, rutinas y otros aspectos del día a día.

## Primer módulo

El primer módulo permitirá gestionar tareas personales:

- Crear tareas.
- Editar tareas.
- Eliminarlas.
- Marcar tareas como completadas.
- Filtrar por estado y prioridad.
- Organizar tareas por fecha límite.

## Tecnologías

### Backend

- C#
- ASP.NET Core
- Entity Framework Core
- SQLite

### Frontend

- Vue 3
- TypeScript
- Pinia
- Vue Router
- Vite
